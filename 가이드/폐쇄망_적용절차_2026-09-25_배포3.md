## 1. 앱 jar 교체

```bash
./stop-aix.sh
ps -ef | grep dbagent-java | grep -v grep        # 아무것도 안 나와야 정상
cp -p dbagent-java-0.1.0.jar dbagent-java-0.1.0.jar.bak-$(date +%Y%m%d-%H%M)
cp <반입한 jar> dbagent-java-0.1.0.jar
./start-aix.sh
```

## 2. 확인

- F12 → Network에서 `app.js?v=167` (AIX) 확인, 옛 번호면 Ctrl+F5
- 로그에 `ASH backfill for db_id=... minute(s), ... value(s)` 가 오라클 DB 수만큼 (기동 후 수 초 내)
  - `ASH backfill skipped ...` WARN이 있으면 그 줄을 전달해 주세요 (타임아웃 60초 초과 등)
- Current Session: 재기동 직후에도 30분/1시간 그래프가 채워져 있음, 30분·1시간·6시간·24시간 전환 정상, 좌우 그래프 시각 일치
- **RAC 확인 요청**: DB 관리에서 RAC 노드가 SCAN/서비스명(`connect_mode=service`)으로 등록된 항목이 있는지 — 있으면 노드별 sid 등록으로 바꿔야 집계가 정확함
