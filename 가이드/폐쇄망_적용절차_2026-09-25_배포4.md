# 폐쇄망 적용 절차 (2026-09-25) — 배포 ④

> 대상: 전체 작업순서 **D단계**(공용 ASH 구간 조회 + AWR 보충) + **E단계**(Current Session 기능 추가)
> 배포 ①~③을 아직 적용하지 않았다면 이번 jar에 모두 포함되어 있다. 배포 ② 절차서의 2절(sqlrestapi prompt 복사)만 추가로 하면 된다.
> 적용 내용: **jar 교체만** (DB 파일 스키마 변경 없음. 새 설정 키 2개는 없어도 기본값으로 동작)

| 항목 | 요청 원본 | 내용 |
|---|---|---|
| D1·D2 | 1-10·2-1 기반 | 시작·종료 시각으로 ASH를 조회하는 공용 기능. ASH 보관 범위 밖 구간은 AWR(`dba_hist_active_sess_history`)로 채움 |
| E1 | 1-3 | Current Session **좌측 그래프 드래그** → 그 구간의 세션 목록 (6시간/24시간 과거 구간도 가능) |
| E2 | 1-3 | 우측 그래프의 세로 구간 드래그는 의도된 동작. 범례로 숨긴 SQL은 드래그 결과에서도 빠짐 |
| E3 | 1-6 | 우측 Top SQL 그래프 범례 클릭 → 해당 SQL 숨기기/보이기 |
| E4 | 1-7 | Active Session·Active Transaction 탭 **Duration Time(sec) 머리글 클릭 정렬** (긴 순 → 짧은 순 → 원래) |
| E5 | 1-8 | **Remote 탭** 신규 — DB Link로 들어온(IN) / 나가는(OUT) 세션 |

## 1. 앱 jar 교체

```bash
./stop-aix.sh
ps -ef | grep dbagent-java | grep -v grep        # 아무것도 안 나와야 정상
cp -p dbagent-java-0.1.0.jar dbagent-java-0.1.0.jar.bak-$(date +%Y%m%d-%H%M)
cp <반입한 jar> dbagent-java-0.1.0.jar
./start-aix.sh
```

새 설정 키 (선택, `application.properties`에 없으면 기본값):

| 키 | 기본값 | 설명 |
|---|---|---|
| `dbagent.monitor.ash-awr-fallback` | `true` | ASH 보관 범위 밖 구간을 AWR로 채울지. **Diagnostics Pack이 없는 DB라면 `false`** |
| `dbagent.monitor.ash-awr-query-timeout-seconds` | `60` | AWR이 섞인 조회의 타임아웃(초) |

## 2. 확인

- F12 → Network에서 `app.js?v=168`, `style.css?v=47` (AIX). 옛 번호면 Ctrl+F5

| 확인 | 방법 | 기대 결과 |
|---|---|---|
| E1 | Current Session 좌측 그래프를 가로로 드래그 | 세션 목록 창이 열림. 범례에서 CPU를 끄고 드래그하면 CPU 세션이 빠짐 |
| E1 (AWR) | 24시간 버튼 → 그래프 왼쪽(몇 시간 전) 드래그 | 세션 목록이 나옴 (ASH에 없는 구간은 AWR 기준, 10초 간격 샘플이라 세션 수가 적을 수 있음) |
| E3 | 우측 그래프 범례의 SQL 하나 클릭 | 그 SQL 영역이 사라지고 범례가 흐려짐. 30초 뒤 갱신돼도 유지 |
| E2 | E3 상태에서 우측 그래프 드래그 | 숨긴 SQL의 세션은 목록에 없음 |
| E4 | Active Session 탭 Duration Time(sec) 머리글 클릭 | ▼ 긴 순 → ▲ 짧은 순 → ↕ 원래 순서, 3초 자동 갱신 후에도 유지 |
| E5 | Remote 탭 | DB Link 사용 중이면 IN/OUT 행, 없으면 "DB Link로 연결된 세션이 없습니다" |

## 3. 현장 실측 부탁 (D3)

아래를 SQL로 확인해 결과를 전달해 주세요 — 성능 분석(G3)·대시보드 Top(F)에서 과거 구간을 어디까지 볼 수 있는지 정하는 기준이 된다.

```sql
-- ASH 인메모리 보관 범위(인스턴스별로)
SELECT MIN(sample_time), MAX(sample_time), COUNT(*) FROM v$active_session_history;
-- AWR 보존 기간 / 스냅샷 주기
SELECT retention, snap_interval FROM dba_hist_wr_control;
-- Diagnostics Pack 사용 여부
SELECT value FROM v$parameter WHERE name = 'control_management_pack_access';
-- 11g 인스턴스가 있다면: 두 컬럼이 있는지
SELECT column_name FROM dba_tab_columns WHERE table_name = 'DBA_HIST_ACTIVE_SESS_HISTORY' AND column_name IN ('SESSION_TYPE','USER_ID');
```

- 24시간 버튼에서 과거 구간 드래그가 느리면(10초 이상) F12 Network의 `ash_session_detail` 응답 시간도 알려 주세요.
